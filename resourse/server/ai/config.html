AI 助手配置

支持 OpenAI / Ollama / DeepSeek 等兼容服务
仅存储在设备 NVS，不会明文暴露
如 gpt-4o-mini / deepseek-chat / qwen2.5
推理模型 + 多轮大上下文生成较慢，建议 ≥90s；过大则无响应时等待过久
Lua 游戏生成需要较大值，建议 ≥4096；过大会增加等待与费用

语音识别（ASR，可选）

用于 AI 助手 🎤 语音输入。留空 = 回落用上面的 API 地址（若那是 Ollama 会报 model not found，需显式填写）。
本地 crispasr：crispasr --server --host 0.0.0.0 --port 8080 → 填 http://<PC-IP>:8080
OpenAI 兼容端点 /v1/audio/transcriptions；crispasr 也可用 /inference
OpenAI 云端用 whisper-1；本地服务忽略此字段
如 zh / en（留空按默认 zh）
